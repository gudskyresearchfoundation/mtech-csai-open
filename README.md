# MTech-CSAI-Open

**Free, university-independent learning resources for M.Tech Computer Science and Artificial Intelligence.**

Slide decks, notes, practice problems, code and last-minute revision pages for every subject, maintained by [Gudsky Research Foundation](https://gudsky.org) and contributors. Any M.Tech student, from any university, can use them.

> **Status: early stage.** The structure below is the plan and will be updated soon. Right now only the **Foundation Mathematics** slide decks (PPT) are available. The other folders are being filled in.

---

## Repository structure

Every subject has its own folder, and every subject folder has the same five sub-folders:

```
mtech-csai-open/
├── README.md
├── LICENSE
│
├── Foundation Mathematics/          <- available (PPT)
│   ├── PPT/                         slide decks
│   ├── Code/                        runnable notebooks and scripts
│   ├── Notes/                       detailed written notes
│   ├── Practice Problems/           questions with answers
│   └── Last Minute Revision/        quick-revision HTML pages
│
├── Advanced Algorithms/             <- planned
├── Machine Learning/                <- planned
├── Deep Learning/                   <- planned
├── Natural Language Processing/     <- planned
├── Computer Vision/                 <- planned
├── Reinforcement Learning/          <- planned
├── Research Methodology and IPR/    <- planned
└── ...more subjects to come
```

### What each sub-folder holds

| Folder | Contents |
|---|---|
| **PPT** | Slide decks, built from Basic to Advanced, with solved problems |
| **Code** | Jupyter notebooks and Python scripts that reproduce the examples |
| **Notes** | Detailed theory notes in readable form |
| **Practice Problems** | Questions graded Basic to Advanced, with answers |
| **Last Minute Revision** | Self-contained `.html` pages: download one and open it in any browser for a quick revision before the exam. No installation or internet needed. |

### Foundation Mathematics: units available

1. Linear Algebra
2. Calculus
3. Probability and Statistics
4. Discrete Mathematics
5. Optimization
6. Numerical Methods
7. Information Theory
8. Stochastic Processes (Markov chains, hidden Markov models, MCMC, Gaussian processes)

Each deck has 200 slides, from Basic to Advanced, with a practice set at the end of every module.

## How to use

1. Open the subject you need.
2. Download a deck from **PPT**, or open a **Last Minute Revision** page in your browser.
3. Use **Practice Problems** to test yourself, and **Code** to run the examples.

You can download a single file from GitHub by opening it and choosing *Download raw file*, or download the whole repository with *Code → Download ZIP*.
